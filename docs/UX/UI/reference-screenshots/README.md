# Reference Screenshots

Esta carpeta guarda las capturas canonicas del Business Panel y las capturas comparativas del superadmin.

Formato de nombre:

```text
[area]-[componente]-[estado]-[tema]-[viewport].png
```

Ejemplos:

```text
business-users-page-default-light-1440.png
business-users-stats-modal-overview-dark-1366.png
admin-users-page-default-light-1440.png
admin-users-stats-modal-overview-dark-1366.png
```

Reglas:

- Las capturas `business-*` son la referencia visual.
- Las capturas `admin-*` son la implementacion migrada que se compara contra la referencia.
- Incluir tema y viewport en el nombre.
- No guardar capturas temporales con nombres genericos.
- Si una captura necesita notas, crear un `.md` con el mismo nombre base.
